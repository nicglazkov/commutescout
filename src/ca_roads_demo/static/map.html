      A key calls the same tools as the MCP server over plain HTTP, at mcp.commutescout.com/v1. Free keys get 2,000 requests a day, Pro keys 10,000, counted once per account across all of its keys; ask when you need more. A key is shown once, when it is created.

      Checking the feeds…

      Every source, with coverage and update rates

      Data: CHP, Caltrans, WFIGS, CAL FIRE, NWS, USGS, TomTom, 511 SF Bay, and the state DOT and 511 services listed above (including data powered by 511NY and TravelMidwest). Independent service, not affiliated with any agency. Conditions change fast; verify before you drive (511 or your state DOT). Questions are logged anonymously to improve answers. Traffic is measured with cookieless Cloudflare Web Analytics. Route previews and place lookup come from Stadia Maps, which sees the coordinates involved. The Positron and Bright base maps load tiles from OpenFreeMap, which sees your IP address and the map area you are viewing; the other base maps are drawn from files we host.
