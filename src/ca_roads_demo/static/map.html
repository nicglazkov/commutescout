    About the data

    Data: CHP, Caltrans, WFIGS, CAL FIRE, NWS, USGS, TomTom, 511 SF Bay, and the state DOT and 511 services listed in the data-sources panel (including data powered by 511NY and TravelMidwest). Independent service, not affiliated with any agency. Conditions change fast; verify before you drive (511 or your state DOT). Questions are logged anonymously to improve answers. Traffic is measured with cookieless Cloudflare Web Analytics. Map tiles, route previews, and place lookup come from Stadia Maps (data (c) OpenStreetMap contributors), which sees the coordinates involved. Privacy Terms Data sources Pricing About Contact GitHub
